# Kit de Instagram — 15 skills para Claude Code

1. Rellena `instagram/marca.md` (una vez).
2. Abre Claude Code en este repo y escribe el comando.

| Comando | Para qué |
|---------|----------|
| `/ig-reel <tema>` | Borrador de reel: hook (26 fórmulas), guion, texto en pantalla, beat sheet |
| `/ig-viral` | Analiza tus métricas y encuentra lo que funciona |
| `/ig-caption` | Captions en 3 largos + A/B de primera línea |
| `/ig-carousel <tema>` | Carrusel slide a slide (y PNGs 1080×1350 si quieres) |
| `/ig-story` | Secuencia de historias con stickers |
| `/ig-profile` | Bio, nombre, destacados y fijados |
| `/ig-plan` | Calendario de contenido |
| `/ig-human` | Que el texto no suene a IA |
| `/ig-comment` | Comentarios de valor en cuentas ajenas |
| `/ig-reply` | Clasifica y responde los comentarios que recibes |
| `/ig-dm` | DMs: leads, palabra clave, seguimientos, objeciones |
| `/ig-repurpose` | Un contenido → reels, carrusel, historias |
| `/ig-referentes` | Analiza cuentas ajenas: su reel más viral, por qué fallaron los flojos, y guarda lo aprendido |
| `/ig-sonido` | Sonido profesional: música con ducking, efectos al fotograma, master −14 LUFS y QA |
| `/ig-audit` | Auditoría completa con plan de 30 días |

Los resultados se guardan en `instagram/reels/`, `instagram/carruseles/`, `instagram/plan/` e `instagram/analisis/`.

**Límite:** las skills no publican ni leen Instagram por sí solas; trabajan con lo que pegas (textos, capturas, CSV de Meta Business Suite).
